# Диктовка — голосовой ввод в любое поле Windows

Нажал **Ctrl+Пробел**, говоришь, нажал ещё раз — текст появился там, где стоит курсор.
В Claude Code, в браузере, в Telegram, в Word — где угодно. **Без ограничения по длине**: хоть час.

![Как выглядит плашка записи](preview.svg)

## Зачем

- Встроенная диктовка Claude Code **обрывается через 2 минуты** и есть только в главном поле.
  В окне вопроса с вариантами ответа («Свой ответ») микрофона нет вообще — а там часто приходится объяснять подробно.
- Работает одинаково везде: браузер (Claude.ai, ChatGPT, почта), Telegram, документы — одна кнопка на всё.
- Win+H (диктовка Windows) — хороший запасной вариант, но своих имён и терминов ему не объяснишь.

Распознаёт **Whisper large-v3** на серверах Groq — одна из самых точных открытых моделей распознавания речи.
10 секунд речи → текст меньше чем за секунду. Бесплатно: лимит Groq — около 8 часов аудио в сутки.

## Перед установкой — две вещи

1. **VPN.** Groq не работает из России — нужен включённый VPN и при получении ключа, и во время диктовки.
2. **Бесплатный ключ Groq** (2 минуты): открыть [console.groq.com](https://console.groq.com) → войти через Google
   или GitHub → слева **API Keys** → **Create API Key** → скопировать (начинается на `gsk_`).
   Если у тебя уже есть ключ Groq от другого проекта — подойдёт он.

## Установка — одна команда

Открыть PowerShell (Пуск → набрать `powershell` → Enter) и вставить:

```powershell
iwr -useb https://raw.githubusercontent.com/slautin-av/diktovka/main/install.ps1 | iex
```

Установщик сам поставит Python, если его нет, спросит ключ и проверит его, создаст ярлык «Диктовка» на рабочем
столе и в автозагрузке и запустит программу. Повторный запуск той же команды — обновление до свежей версии
(ключ и настройки сохраняются).

Если антивирус спросит, разрешить ли программе микрофон, — «Разрешить».

## Как пользоваться

1. Поставь курсор в поле, куда нужен текст.
2. **Ctrl+Пробел** — короткий сигнал, внизу экрана плашка с таймером и полоской громкости.
3. Говори сколько нужно.
4. **Ctrl+Пробел** ещё раз — «Распознаю…», через секунду-две текст вставится в поле.

**Esc** во время записи — отмена. Текст после вставки остаётся в буфере обмена: если курсор стоял не там —
Ctrl+V в нужном месте. Все тексты копятся в `istoriya.md`, так что ничего не теряется.

## Свой словарь — главная настройка

Распознаватель не знает твоих имён, названий фирм и терминов. Пример из проверки: без словаря «МультиКрит»
превратился в «Multiquid». Открой `config.json` в папке программы и допиши свои слова в `prompt` через запятую:

```json
"prompt": "Диктовка. Claude Code, VS Code, GSD, GitHub, Telegram, Groq, МультиКрит, Иван Петрович, ООО «Ромашка»."
```

После правки — перезапустить программу (ярлык «Диктовка»).

Остальные настройки там же:

| Настройка | Что меняет |
|---|---|
| `hotkey` | сочетание клавиш: `ctrl+space`, `alt+space`, `f9`, `ctrl+shift+d`… |
| `paste` | `false` — не вставлять самому, только класть в буфер обмена |
| `language` | язык речи: `ru`, `en`, `uk`… |
| `model` | `whisper-large-v3` (точнее) или `whisper-large-v3-turbo` (быстрее) |

Ctrl+Пробел, пока программа работает, принадлежит ей. Если ты пишешь код руками в VS Code, где это сочетание
открывает подсказки, — поменяй `hotkey`.

## Если что-то не так

Плашка сама говорит, в чём дело:

| Плашка пишет | Что делать |
|---|---|
| «нет связи с Groq» / «Groq не пускает из твоей страны» | включить VPN |
| «Groq не принял ключ» | запустить установку ещё раз и вставить ключ заново |
| «Микрофон молчит» | Параметры Windows → Конфиденциальность → Микрофон → разрешить доступ классическим приложениям |
| «… занята другой программой» | сочетание клавиш занято — поменять `hotkey` в `config.json` |

Если сеть подвела, запись не пропадает: аудио последних 20 диктовок лежит в папке `zapisi`.
Подробности сбоев — в `oshibki.log`.

Папка программы: `%LOCALAPPDATA%\diktovka` (вставь это в адресную строку Проводника).
Выключить: правый клик по плашке во время записи → «Выключить диктовку».

## Приватность

Звук уходит на распознавание в Groq (США) и больше никуда. Тексты и записи хранятся только у тебя на компьютере.
Ключ Groq лежит в `groq.env` в папке программы.

## Удаление

```powershell
iwr -useb https://raw.githubusercontent.com/slautin-av/diktovka/main/uninstall.ps1 | iex
```

Убирает программу, ключ, настройки, ярлыки и автозагрузку. История диктовок переезжает на рабочий стол.

## Требования

Windows 10 или 11. Python ставится сам. Mac и Linux — нет.
